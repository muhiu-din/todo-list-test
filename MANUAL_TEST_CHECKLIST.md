# Manual QA Checklist

Use two Android devices or one device and one Android emulator.

1. Sign up with a new account on device A.
2. Sign up with a different account on device B.
3. Create a team on device A.
4. Share the invite code and join on device B.
5. Confirm both devices display the team and member list.
6. Create a shared list on device A.
7. Confirm the list appears on device B.
8. Add a shared task on device A and confirm it appears on device B.
9. Complete the task on device B and confirm device A updates.
10. Edit the task title on device A and confirm device B updates.
11. Delete the task and confirm it disappears on both devices.
12. Add a shared task with a reminder and confirm it is visible on both devices.
13. Confirm reminders ring after each device has synced the task.
14. Remove a member as owner and confirm access is removed.
15. Regenerate the invite code and confirm the old code no longer joins.
16. Leave a team as a member.
17. Add a Personal task and confirm it is separate from team lists.
18. Log out and log back in; confirm tasks remain.
19. Use Settings to request a password reset.
20. Turn on dark mode if implemented by the current build.
21. Turn on airplane mode, attempt a change, reconnect, and confirm the final state syncs.
22. Tap a reminder notification and verify it opens the app.
23. Install the APK on a clean phone and verify notification permission appears.
